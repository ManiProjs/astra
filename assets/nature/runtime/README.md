# Runtime vegetation assets

These six GLBs are runtime-resolution derivatives of the CC0 Poly Haven sources in the parent
asset folders. Embedded images were downsampled to a maximum dimension of 256px to reduce GPU
texture residency on unified-memory systems. Geometry, materials, UVs, alpha channels, and source
model structure are preserved. Source/license metadata remains in each parent folder's
`source.json` and in `../README.md`.
